# Studio helpers

- Debug jump: in Play, add a StringValue named DebugGoto under your Player (or set the attribute DebugGoto) to menu, tome:collection, tome:badges, tome:flair, tome:legend, tome:cardsets, tome:stats, news or round1 (fixed seed, first options picked). The Output prints `[DebugGoto] <value> ok`. Tome sub-tabs, shop and spectate cannot be reached from script.
