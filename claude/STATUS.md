# Wildcard Tavern — Status

- **3D room:** removed. The tavern is a 2D painted backdrop (Client/ArtAssets.lua); there is no 3D scene, building load, camera or Lighting setup. `TavernScene.server.lua` and its marketplace building load were deleted in `d68922f`; stale comments pointing at them were cleaned up on 2026-11-03.
- **Tests:** `lua5.3 tools/run_tests_local.lua` (any Lua 5.1+ works, e.g. plain `lua`) — 381 passing as of 2026-11-07.
- **Client hub:** `src/Client/init.client.lua` is at the 200-local limit for its main chunk. Add new code in modules or `do...end` blocks.
- **One More Round (continue):** one per run, restoring the lost round to its start (`RunState.roundStartSnapshot`, taken in `startRound`; the rng isn't rewound). Each player gets one free per UTC day (`PlayerProfile.freeContinueDateKey`), offered before the paid Developer Product (`GamePasses.DeveloperProducts`, placeholder `productId = 0`; Studio grants it free). The server decides which one applies (`continueOffer`, `RequestContinue`, `ProcessReceipt`). Revived runs go to separate "Revived" Daily/Weekly boards (store names bucketed on `SeededRng.VERSION`) and don't count toward `bestNightReached`, `runsWon` or the achievements built on them. Game Over and the leaderboard (Standard/Revived toggle, default Standard) show a "Revived" badge.
- **UI skin:** `VisualHelpers.polishPanel`/`polishButton` give every panel and button the sidebar look: gold ring, gold inner rim, gold corner brackets and studs on panels at least 56px, and a standard 6px corner radius (radius 20+ is kept for round medallions). `polishPanel(x, r, "wood")` is for menus and dialogs, `"parchment"` for reading screens. The ornaments are skipped on ScrollingFrames, see-through elements and anything holding a UIListLayout/UIGridLayout.
- **Settings:** saved in `PlayerProfile.settings` (`SETTING_SPECS`: musicVolume, sfxVolume, muted, animSpeed, reduceShake, colorblindSuits, confirmDiscard). Profiles without the table get defaults. The client copy is `Client/ClientSettings.lua`, which loads once from the state push and saves through the `SetSetting` remote (debounced). The volume button opens `VolumePanel.lua`: Music, SFX and Mute only. The ⚙ panel (`Settings.lua`, wood) has three sections: Display (animation speed, reduce shake, colorblind suits), Gameplay (confirm discard) and Account (How to Play, Leaderboards, Main Menu). There is no Jukebox (its code in `Sound.lua` is unused and can be deleted). Free "Fast" speed is 1.35×; with the Fast Forward pass it's 1.8× (`PlayerProfile.animationPaceDivisor`). Normal speed is 1× for everyone. Reduce shake turns off `screenShake`. Colorblind gives each suit its own color plus a corner suit letter (`CardFace`).
- **Collection:** `Client/Collection.lua` (parchment) has tabs for Patrons, Recipes, Boss Rounds, House Passes and Titles, each with its completion %, plus an overall % bar showing the next milestone. Discovered entries show their icon, name and a rarity glow. Undiscovered ones are dark "???" silhouettes. Tapping an entry opens a detail card with its effect and `flavorText`; Titles are equipped there. The rules live in `Engine/CollectionBook.lua`: tabs, rarity (an entry's `rarity` field, otherwise worked out from price or `minNight`), completion, and the editable `Milestones` table (25% title, 50% card back, 100% title + card back). Every registry entry has a `flavorText`.
- **Discovery:** `PlayerProfile` keeps `discoveredPatronIds`, `discoveredRecipeIds`, `discoveredBossIds` and `discoveredHousePassIds`. An entry counts once it's owned, offered in the shop, revealed in a pack, or faced as a boss (`CollectionBook.gatherSeen`, recorded on every `syncProfileFromSession`). Titles count when their Achievement is unlocked. Milestone-reward titles (`milestoneReward = true`) are granted into `rewardTitleIds` and don't count toward completion. Milestone card backs (`Engine/CardBacks.lua`) are unlocked into `unlockedCardBackIds`.
- **Kid-safe naming:** the shop is "The Counter" (formerly "The Bar"). There are no drink emoji.
- **UI palette:** fixed (`Client/Palette.lua`). There is no theme picker and no per-theme recoloring.
- **Cosmetic Sets:** `Engine/CosmeticSets.lua` is the registry: each set is a card back plus a backdrop image, with an `unlock` of `default`, `tips` (price), `journey` (runs won), `achievement` (id) or `gamepass` (id). Profile fields: `ownedSetIds` (Tips buys), `equippedSetId` (falls back to the default if unknown or locked, see `CosmeticSets.effectiveId`). The server handles `BuyCosmeticSet` / `EquipCosmeticSet` and sends `state.cosmetics`. UI: the "Card Sets" button in the Collection header opens `Client/CosmeticSetsPanel.lua`. `Client/CosmeticSetsView.lua` applies the equipped set (backdrop swap, card back tint). Card backs are equipped separately from sets: `profile.equippedCardBackId` (nil = use the set's back), unlocked when earned (`unlockedCardBackIds`) or when their set is unlocked (`CosmeticSets.isCardBackUnlocked`, `effectiveCardBackId`, `equipCardBack`; server remote `EquipCardBack`, state `cosmetics.cardBackId`). The Card Sets panel has a Card Backs section with "Match my set". Backdrop images are `rbxassetid://0` placeholders; see `claude/ART_TODO.md`. Old `ownedThemeIds`, `equippedTheme` and `customPlaylist` are ignored on load. Game Passes: Fast Forward and Golden Gala (`set_golden_gala`, placeholder id 0).
- **Journey:** `Client/Journey.lua` has two tabs. "Tavern Map" (`JourneyMapView.lua`, default) draws the 8 Night nodes, the Endless doors and 3 Endless milestone nodes (Nights 10, 15, 20) at normalized `x`/`y` positions on a canvas (`JourneyMap.Config.journeyMapImage` = painted background, `rbxassetid://0` or a failed load falls back to the UI parchment). Nodes show cleared (gold ring + check), current (pulse), locked (dimmed, reward preview) and a boss-tier badge. Tapping one opens a detail card (reward preview, how it unlocks, Equip). When the map opens after a new clear, the path draws to the next node, it lights up and a reward toast pops (respects animation speed and reduce shake). The header shows Journey completion % and a next-reward hint; past Night 8 it switches to the purple Endless style (`JourneyMap.EndlessTheme`, also used by Round Select). "This Night" is the old round-by-round road. Content lives in `Engine/JourneyMap.lua` (names, descriptions, positions, rewards; reward kinds `cardBack`, `set`, `title`). Clearing a Night means beating its boss round. First clears (Nights 1-8 and Endless milestone Nights) are saved in `PlayerProfile.clearedNightIds` and rewards granted by `JourneyMap.recordNightsCleared` / `recordEndlessCleared` (server `syncProfileFromSession`, Revived runs excluded; `migrate` re-grants). Equipping goes through the `EquipJourneyReward` remote -> `JourneyMap.equipReward`, which refuses unearned rewards. `NightVictory.lua` shows the "Tavern Champion" panel (hands played, best hand, Patrons used) when `wonRun` flips, with a button into Endless. Art to supply: `claude/ART_TODO.md`.
- **Backdrop styles:** each Cosmetic Set can have a `backdropStyle` (`Engine/CosmeticSets.lua`, checked by `validateStyle`): image tint, flat overlay, a stepped vignette and layers (`snow`, `sparks`, `dust`, `bunting`, each capped at 30). `Client/BackdropStyles.lua` draws them with UI only in a click-through `BackdropFX` frame at the host's ZIndex; `CosmeticSetsView` applies the equipped set's style over the gameplay, Shop, Round Select and Journey map backdrops. Winter, Festival and Closing Time have styles; Classic and Golden Gala keep the plain backdrop. Particles reuse frames, run only while the host is visible, and stop under "Reduce screen shake" (Animation Speed scales their drift). Map nodes are numbered gold rings with a small glyph (`glyph` or `icon` in `JourneyMap`). In Studio only, the map's "Nudge" button shows each node's x/y and lets you drag it; new coordinates print to Output. Map image: `JourneyMap.Config.journeyMapImage`.
- **Poker Hands reference:** `Client/PokerHandsReference.lua` (parchment, dimmed backdrop; closes on Close, outside click or Escape). One row per hand from `HandEvaluator.HandOrder`: name, 5 mini example cards (`HandEvaluator.Examples`, test-checked), Chips x Mult using leveled values (`state.handLevels` + `Scoring.HandLevelGrowth`), "Lv N" badge when level > 0, played count. 0-play rows are dimmed, the most played hand has a ★. Rows size to fit all 9; the list scrolls only on very small panels. The row for the hand the selected cards make is highlighted live via `Client/HandHighlight.lua`, which `refreshScorePreview` in the hub feeds.
- **Corner icon row:** the top-right buttons (Collection, Settings, Poker Hands, Journey, Music) are children of one right-aligned `CornerIconRow` (UIListLayout, `LayoutOrder`), so a hidden button closes the gap. Ring is bronze 2px with the shared gold inner rim, which follows the host's corner radius (round buttons get a round rim). The music button uses `ArtAssets.cornerIconVolume`, dimmed with a slash when muted or when no track loads. `Sound.lua` warns with the track id on a malformed id, fetch failure or a 6s load timeout (`isMusicUnavailable`, `onMusicAvailability`); it never changes which track plays.
- **Server startup:** engine tests run in a `pcall`; remotes are created right after. The profile/session setup for players already in the server (Studio) is deferred until every remote handler is connected, and each step (`loadProfile`, `startNewSession`, `refreshOwnedGamePasses`) is `pcall`'d with a `[Startup]` warn. Client: Play, Road Ahead, Daily and Weekly go inactive until a `StateUpdated` arrives; after 5s with no reply they show a message and re-enable.
- **Content art:** six art categories share one pipeline (`tools/patron_art/generate_patron_art.py --category <cat>`). Prompts in `tools/patron_art/prompts.json`; style: Roblox avatar 3D render. Categories and their generated Lua maps: `patrons` → `PatronArt.lua` (50 entries, all Image ids wired; `early_bird`, `night_owl` flagged for regen — generated as real birds), `bosses` → `BossRoundArt.lua` (35 entries), `recipes` → `RecipeArt.lua` (58 entries), `housepasses` → `HousePassArt.lua` (7 entries), `titles` → `TitleArt.lua` (16 entries), `rooms` → `RoomArt.lua` (3 entries: corner_table, main_hall, back_room — empty until generated). `tutorial_icons` → `TutorialIconArt.lua` (6 entries, low quality, `style_icon` prefix; drives the How to Play tiles, emoji fallback). `map_nodes` → `MapNodeArt.lua` (11 entries: 8 landmarks, `wax_seal_gold`, `endless_portal`, `hero_token`; all 11 Image ids wired). `backgrounds` → `BackgroundArt.lua` (8 entries, 1536x1024 low quality, own `style_background` prefix: `round_select_bg` behind RoundSelect cards; `shop_bg` / `game_over_win_bg` via `ArtAssets.lua`; `journey_map` via `JourneyMap.Config`; four `backdrop_*` via `CosmeticSets`; each falls back to its old look if the id is `rbxassetid://0`). The four new non-patron maps are empty (`return {}`) until art is generated; UI falls back to emoji icon or plain dark panel. `Engine/ContentArt.lua` is the central lookup: `ContentArt.getImageId(tab, id)` accepts both ContentArt-style keys (`boss_rounds`, `house_passes`) and CollectionBook tab ids (`bosses`, `housePasses`) via aliases. Art appears in: sidebar patron seats, Shop offer rows, Shop My Patrons, pack reveal, Collection tiles and detail cards, RoundSelect boss portrait and scene images, PhaseA boss intro, Journey tab, JourneyMapView title swatches. Pipeline: generate → upload → Studio execute_luau to resolve Image ids → `lua` to write the map → commit. Run `python3 tools/patron_art/generate_patron_art.py estimate` for counts and cost.
