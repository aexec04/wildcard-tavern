# Wildcard Tavern — Status

- **3D room:** removed. The tavern is a 2D painted backdrop (Client/ArtAssets.lua); there is no 3D scene, building load, camera or Lighting setup. `TavernScene.server.lua` and its marketplace building load were deleted in `d68922f`; stale comments pointing at them were cleaned up on 2026-11-03.
- **Tests:** `lua5.3 tools/run_tests_local.lua` (any Lua 5.1+ works, e.g. plain `lua`) — 364 passing as of 2026-11-04.
- **Client hub:** `src/Client/init.client.lua` is at the 200-local limit for its main chunk. Add new code in modules or `do...end` blocks.
- **One More Round (continue):** one per run, restoring the lost round to its start (`RunState.roundStartSnapshot`, taken in `startRound`; the rng isn't rewound). Each player gets one free per UTC day (`PlayerProfile.freeContinueDateKey`), offered before the paid Developer Product (`GamePasses.DeveloperProducts`, placeholder `productId = 0`; Studio grants it free). The server decides which one applies (`continueOffer`, `RequestContinue`, `ProcessReceipt`). Revived runs go to separate "Revived" Daily/Weekly boards (store names bucketed on `SeededRng.VERSION`) and don't count toward `bestNightReached`, `runsWon` or the achievements built on them. Game Over and the leaderboard (Standard/Revived toggle, default Standard) show a "Revived" badge.
- **UI skin:** `VisualHelpers.polishPanel`/`polishButton` give every panel and button the sidebar look: gold ring, gold inner rim, gold corner brackets and studs on panels at least 56px, and a standard 6px corner radius (radius 20+ is kept for round medallions). `polishPanel(x, r, "wood")` is for menus and dialogs, `"parchment"` for reading screens. The ornaments are skipped on ScrollingFrames, see-through elements and anything holding a UIListLayout/UIGridLayout.
- **Settings:** saved in `PlayerProfile.settings` (`SETTING_SPECS`: musicVolume, sfxVolume, muted, animSpeed, reduceShake, colorblindSuits, confirmDiscard). Profiles without the table get defaults. The client copy is `Client/ClientSettings.lua`, which loads once from the state push and saves through the `SetSetting` remote (debounced). The volume button opens `VolumePanel.lua`: Music, SFX and Mute only. The ⚙ panel (`Settings.lua`, wood) has three sections: Display (animation speed, reduce shake, colorblind suits), Gameplay (confirm discard) and Account (How to Play, Leaderboards, Main Menu). There is no Jukebox (its code in `Sound.lua` is unused and can be deleted). Free "Fast" speed is 1.35×; with the Fast Forward pass it's 1.8× (`PlayerProfile.animationPaceDivisor`). Normal speed is 1× for everyone. Reduce shake turns off `screenShake`. Colorblind gives each suit its own color plus a corner suit letter (`CardFace`).
- **Collection:** `Client/Collection.lua` (parchment) has tabs for Patrons, Recipes, Boss Rounds, House Passes and Titles, each with its completion %, plus an overall % bar showing the next milestone. Discovered entries show their icon, name and a rarity glow. Undiscovered ones are dark "???" silhouettes. Tapping an entry opens a detail card with its effect and `flavorText`; Titles are equipped there. The rules live in `Engine/CollectionBook.lua`: tabs, rarity (an entry's `rarity` field, otherwise worked out from price or `minNight`), completion, and the editable `Milestones` table (25% title, 50% card back, 100% title + card back). Every registry entry has a `flavorText`.
- **Discovery:** `PlayerProfile` keeps `discoveredPatronIds`, `discoveredRecipeIds`, `discoveredBossIds` and `discoveredHousePassIds`. An entry counts once it's owned, offered in the shop, revealed in a pack, or faced as a boss (`CollectionBook.gatherSeen`, recorded on every `syncProfileFromSession`). Titles count when their Achievement is unlocked. Milestone-reward titles (`milestoneReward = true`) are granted into `rewardTitleIds` and don't count toward completion. Milestone card backs (`Engine/CardBacks.lua`) are unlocked into `unlockedCardBackIds`.
- **Kid-safe naming:** the shop is "The Counter" (formerly "The Bar"). There are no drink emoji.
- **UI palette:** fixed (`Client/Palette.lua`). There is no theme picker and no per-theme recoloring.
- **Cosmetic Sets:** `Engine/CosmeticSets.lua` is the registry: each set is a card back plus a backdrop image, with an `unlock` of `default`, `tips` (price), `journey` (runs won), `achievement` (id) or `gamepass` (id). Profile fields: `ownedSetIds` (Tips buys), `equippedSetId` (falls back to the default if unknown or locked, see `CosmeticSets.effectiveId`). The server handles `BuyCosmeticSet` / `EquipCosmeticSet` and sends `state.cosmetics`. UI: the "Card Sets" button in the Collection header opens `Client/CosmeticSetsPanel.lua`. `Client/CosmeticSetsView.lua` applies the equipped set (backdrop swap, card back tint). Card backs are equipped separately from sets: `profile.equippedCardBackId` (nil = use the set's back), unlocked when earned (`unlockedCardBackIds`) or when their set is unlocked (`CosmeticSets.isCardBackUnlocked`, `effectiveCardBackId`, `equipCardBack`; server remote `EquipCardBack`, state `cosmetics.cardBackId`). The Card Sets panel has a Card Backs section with "Match my set". Backdrop images are `rbxassetid://0` placeholders; see `claude/ART_TODO.md`. Old `ownedThemeIds`, `equippedTheme` and `customPlaylist` are ignored on load. Game Passes: Fast Forward and Golden Gala (`set_golden_gala`, placeholder id 0).
- **Journey:** `Client/Journey.lua` has two tabs. "Tavern Map" (`JourneyMapView.lua`, default) shows the 8 named Night locations and an Endless node on a winding path, with boss tier stars, reward previews on locked nodes, "Earned" on cleared ones, and path progress up to the furthest Night reached. Past Night 8 the header switches to a purple "Endless Nights" style. "This Night" is the old round-by-round road. Content lives in `Engine/JourneyMap.lua` (name, description, icon, reward per Night; reward kinds `cardBack`, `set`, `title`). Clearing a Night means beating its boss round; `JourneyMap.nightsClearedFor(state)` counts it as soon as the boss round is won. First clears are saved in `PlayerProfile.clearedNightIds` and rewards granted by `JourneyMap.recordNightsCleared` (server `syncProfileFromSession`, Revived runs excluded; `migrate` re-grants). Rewards: titles (Nights 1, 4, 8), card backs (2, 6), sets (3, 5, 7).  `NightVictory.lua` shows a short "The Tavern Is Yours!" banner when `wonRun` flips.
