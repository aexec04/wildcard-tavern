# Implemented Features

A snapshot of what's actually built and working in Wildcard Tavern's engine and
client, generated by scanning the live source tree. Grouped by system, with
the files that implement each one, the core formulas/contracts involved, and
any genuine TODOs/stubs found in the code (as opposed to things that just
*look* incomplete but are deliberate design decisions — those are called out
explicitly so they don't get "fixed" by accident).

This project renames every Balatro-style mechanic to its own kid-friendly
tavern/diner theme (no real alcohol references) — see `claude/design-doc.md`
and `claude/feature-expansion-plan.md`'s naming key for the full reference
term → our term table. `SPECS.md` in the repo root still uses the *original*
Balatro names (Jokers, Steel cards, Tarot/Planet cards, etc.) — cross-reference
against the naming key before assuming something in it is missing.

Engine-layer correctness is covered by `src/Shared/Tests/EngineTests.lua`
(224 tests as of this scan, runnable with no Roblox install via
`lua5.3 tools/run_tests_local.lua`). Client-side Luau (everything under
`src/Client/`) has **no automated test coverage** — Roblox APIs don't exist
outside Studio, so the most this repo can do standalone is a syntax check
(`luac5.3 -p <file>`), not an actual run.

## Patrons

*(Balatro's Jokers)*

**Files:** `src/Shared/Engine/Patrons.lua` (definitions), `src/Shared/Engine/Scoring.lua`
(applies effects/Specials every hand), `src/Shared/Engine/RunState.lua` (slot
cap, buy/sell, Special assignment), `src/Client/Shop.lua` (buy/sell UI),
`src/Client/Sidebar.lua` (seat row + live tooltips), `src/Client/Collection.lua`
(full-roster gallery).

**Count:** 31 definitions in `Patrons.Definitions`.

**Core contract:** `effect(handResult, context) -> nil | { chips, mult, multMultiplier, tips }`,
a pure function called every hand from `Scoring.calculate`. An optional
`onRoundWin(state)` hook fires once per round won for effects that aren't
tied to a specific hand (economy Patrons). A Patron can also carry a Special
(Silver/Gold/Rainbow/Reserved) via `state.ownedPatronSpecials[patron.id]`,
which `Scoring.calculate` folds in exactly like a card's Special.

**Slot cap:** `RunState.DefaultConfig.patronSlotLimit = 5`, raised +1 per
owned Patron with a Reserved Special, +1 more with the Extra Seating House
Pass (`RunState.patronSlotLimit`).

**Example mechanism spread:**
- Flat bonus: `the_regular` — `{ mult = 4 }` every hand.
- Held-card scaling: `house_favorite` — XMult scales with Kings currently held.
- Economy/`onRoundWin`: `tip_jar` — `+4` Tips on every round win.
- Copy-a-neighbor (Blueprint-style): `the_apprentice`/`the_understudy`/`second_opinion`.
- Pure marker, no `effect`/`onRoundWin` of its own: `nest_egg` — checked by id
  in `RunState.playHand` to raise the universal round-win interest cap from
  +5 to +10 (see Core Run Loop below).

**Known stub:** `RunState.lua`'s `DefaultConfig` comment block still says
*"With 22 Patrons in the pool..."* — stale, the real count is 31. Cosmetic
doc-comment drift, not a functional bug.

## Garnishes & Specials

*(Balatro's card Enhancements and Editions — grouped together here since both
live in `Card.lua` as simple id→definition tables scored the same way)*

**Files:** `src/Shared/Engine/Card.lua` (definitions), `src/Shared/Engine/Scoring.lua`
(per-hand application, Brittle's shatter roll), `src/Shared/Engine/RunState.lua`
(Golden Garnish's held-at-round-end Tips payout).

**8 Garnishes** (`Card.Garnishes`):

| id | effect |
|---|---|
| `sweet` | +30 Chips when scored |
| `zesty` | +4 Mult when scored |
| `houseBlend` | counts as every suit at once (completes Flushes/suit bonuses) |
| `brittle` | x2 Mult when scored; 1-in-4 chance it shatters and leaves the deck forever |
| `iron` | x1.5 Mult per copy currently **held** (not played) |
| `barToken` | +50 Chips; a token card with no rank/suit, fits any hand |
| `golden` | +3 Tips if still held in hand at round end |
| `lucky` | 1-in-5 chance of +20 Mult, separately 1-in-15 chance of +20 Tips |

**4 Specials** (`Card.Specials`):

| id | effect |
|---|---|
| `silver` | +50 Chips |
| `gold` | +10 Mult |
| `rainbow` | x1.5 Mult (the XMult channel) |
| `reserved` | +1 Patron slot — Patron-only, no chips/mult/xmult |

**Core formula** (`Scoring.lua`):
```
Chips = HandBase.chips + HandLevelGrowth.chips*level + sum(per-card Chips)
Mult  = HandBase.mult  + HandLevelGrowth.mult*level  + sum(per-card Mult) + Patron flat-Mult bonuses
XMult = product of every x-multiplier source (Rainbow Special, Iron Garnish, some Patrons)
mult  = Mult * XMult
Score = Chips * mult
```
Every individual contribution is also recorded in `extra.breakdown`, each
entry shaped `{ kind = "chips"|"mult"|"xmult"|"tips", amount, label, source }`,
where `source.type` is `"hand"`, `"card"`, `"heldCard"`, or `"patron"` — this
is what drives the client's card-by-card scoring reveal (see UI/Audio below).

**Known stub:** none found.

## House / Menu / Secret Recipes

*(Balatro's Tarot / Planet / Spectral cards)*

**Files:** `src/Shared/Engine/Recipes.lua` (definitions: 22 House, 9 Menu, 15
Secret — 46 total), `src/Shared/Engine/Packs.lua` (how they're revealed),
`src/Shared/Engine/RunState.lua` (buy/use/cap), `src/Client/Shop.lua` (My
Recipes tab + target-card picker).

**Core contract:** `apply(state, opts, deps) -> ok, message`. `opts` is
recipe-specific (`cardIndices`, `suit`, `rng`), `deps` is injected by
`RunState.useRecipe` — `{ Patrons, patronSlotLimit, recipeSlotLimit, totalHeldRecipes }`
— so a Recipe can read other systems without `Recipes.lua` needing to
`require` them directly.

**Example spread:** `sugar_rush` (House, adds Sweet Garnish to 1-2 selected
cards), the 9 auto-generated Menu Recipes (one per poker hand type, each
levels `state.handLevels[handName] += 1`), `star_treatment` (Secret, grants a
Gold Special to a random owned Patron).

**Acquisition:** Pack reveals only (House/Menu/Secret/Grab Bag packs via
`RunState.resolvePack`). `RunState.buyHouseRecipe`/`buyMenuRecipe`/
`buySecretRecipe` still exist, fully implemented and tested, but nothing in
the client UI calls them — a **deliberate Phase 1c decision** (packs replaced
direct-buy so the shop stays exciting/random), not unfinished work.

**Shared slot cap:** `RunState.recipeSlotLimit = 2`, shared across all three
categories combined (`totalHeldRecipes` sums House+Menu+Secret), enforced at
5 separate insertion points: shop buy, pack resolve, the Blue Stamp reward,
the Purple Stamp reward, and the `second_helping` House Recipe's own effect.

**Known stub:** none — the "engine-only, no UI buy button" comments in both
`Recipes.lua` and `RunState.lua` describe the Phase 1c design decision above,
not incompleteness.

## Boss Rounds

*(Balatro's Boss Blinds)*

**Files:** `src/Shared/Engine/BossRounds.lua` (24 definitions),
`src/Shared/Engine/RunState.lua` (interprets every modifier field, in both
`startRound` and `playHand`).

**Modifier fields used across the 24 definitions:** `handSizeDelta`,
`discardsDelta`, `handsPerRoundOverride`, `targetScoreMultiplier`,
`chipsMultiplier`, `multMultiplier`, `tipsLostPerCardPlayed`,
`forcedRandomDiscardsPerHand`, `requiredCardsPerHand`, `noRepeatHandTypes`,
`zeroTipsOnMostPlayedHand`, `debuff` (suit or face-card nullification).

**Progression gating (`minNight`, 3 tiers):**
- Tier 1, Night 1+ (4 modifiers) — mild single-knob stuff
- Tier 2, Night 3+ (14 modifiers) — real strategic restrictions
- Tier 3, Night 6+ (6 modifiers) — the genuinely brutal ones (hard hand caps, doubled halving, forced 1-card hands, tripled target)

`BossRounds.pick(rng, night)` filters to whatever tier is unlocked before
picking randomly. A Boss Round is always the last round of a Night, is never
skippable, and pays double Tips on clear.

**Known stub:** none found.

## Tags

*(Balatro's Skip Tags)*

**Files:** `src/Shared/Engine/Tags.lua` (3 definitions), `src/Shared/Engine/RunState.lua`
(`skipRound`/`canSkipRound`/`currentRoundSkipTag`), `src/Client/RoundSelect.lua`
(Skip button + reward popups).

| id | effect |
|---|---|
| `tip_jar` | instant Tips, scaled by Night (capped below a full round-win reward) |
| `on_the_house` | a free random unowned Patron if there's table room, else falls back to Tip Jar's payout |
| `happy_hour` | flat 3-Tip discount on the very next shop visit's Patron/Pack prices, floored at 1 |

Only ever offered on non-Boss rounds — `state.currentRoundSkipTag` is `nil`
on the Boss round, since the Boss round can never be skipped.

**Scoring choreography (`ScorePopup.lua`):** walks `extra.breakdown` entry by
entry (capped at 8 animated entries), pacing each with a 1.0s stagger, an
escalating-pitch tick sound, a screen shake + particle burst scaled to that
entry's size, and an extra anticipation pause before a big XMult hit — then a
finale re-snaps to the authoritative totals with the biggest shake/thud.

Title (main menu), Gameplay (default), Boss (Boss Round), Shop.

## Core Run Loop & Economy

*(Not one of the 7 requested categories, but a distinct already-built system
worth documenting on its own — mostly `src/Shared/Engine/RunState.lua`.)*

**Target score formula** (`RunState.targetScoreFor`):
```
nightBase       = 100 * 2.5 ^ (night - 1)                      -- unbounded growth per Night
blindMultiplier = 1x (Small, round 1)
                | 1.5x (Big, any round before the last)
                | 2x→6x linear by Night, capped at Night 8, then flat 6x (Boss, last round)
targetScore     = floor(nightBase * blindMultiplier * targetMultiplier * bossModifier.targetScoreMultiplier)
```
`targetMultiplier` is the deck variant/difficulty tier's own multiplier;
`bossModifier.targetScoreMultiplier` (e.g. `house_rules` 1.4x, `big_tab` 3x)
only applies on the Boss round, on top of the Blind multiplier above.

**Ante-cap win condition + Endless Mode:** clearing Night 8's Boss Round sets
`state.wonRun = true`; the run keeps going past that (Endless Mode) with
`nightBase` still climbing unbounded even though the Blind multiplier itself
plateaus at 6x.

**Universal round-win interest:** `+1` Tip per 5 held, capped at `+5` (or
`+10` if `nest_egg` is owned), on every round win.

**Known stub:** none.
